# 标准许可条款 v1

[English](LICENSE-TERMS-V1.en.md) | [简体中文](LICENSE-TERMS-V1.md)

版本标识：`CopyrightLicenseTerms/v1`。以下条款适用于平台上的使用许可。[机制详解](COPYRIGHT-MECHANISM.zh-CN.md)。

1. 授权标的是挂单关联 `workId` 所登记文件指纹对应的作品；登记记录属于权利声明，不构成平台对真实权属的保证。
2. 登记人向接受挂单的钱包授予有期限、非独占、不可转让、不可转授权的使用许可，具体用途以挂单 `scope` 为准。
3. 许可自接受交易的链上时间开始，到 `endsAt` 时终止，区间为 `[startsAt, endsAt)`。
4. 买家支付价格 `P`，登记人预先锁定押金 `D = P + C`，其中 `C` 是固定补偿。双方各自承担网络手续费。一笔交易批量创建挂单不合并各份许可或押金。
5. 成交时，买家价格 `P` 记入登记人可领取余额，押金 `D` 继续锁定。价格收入不是押金退款。
6. 登记人可以在有效期内提前终止。合约按期限 `T` 和已履行秒数计算 `E = floor(P × elapsed / T)`，从押金中给买家 `P − E + C`，给登记人 `E`。终止与结算在同一交易中完成。
7. 正常到期时授权自动失效；任何人可另行触发结算，将 `D` 全部记入登记人可领取余额。结算和提现时间不会延长许可。
8. 如果管理员依线下处理结果在许可到期前撤销登记，该许可立即失效；任何人可逐份触发结算，将该份押金 `D` 全部记入买家。已结算许可不再次赔付；先到期再撤销的许可不改变原结果。
9. 余额入账后由账户持有人发起提现才实际转出 ETH；触发结算者不能改变收款人。状态失效不等于已结算或已提现。
10. 管理员案件报酬来自明确注资、独立记账的费用池，不从买家退款或许可押金中扣除。
11. 系统不保存或交付原始文件，不控制用户设备，也不自动判断现实使用是否符合许可。可选参考链接是公开元数据，不代表内容通过验证。
12. 登记被撤销后，同一文件指纹重新登记会生成新声明，旧声明、旧许可和旧资金记录不删除、不迁移。
13. 查询结果只说明平台许可记录在指定时间是否有效，不代替现实权属判断、线下裁决或适用法律。
